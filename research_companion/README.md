# Interactive research companion

The existing seven-section React/TypeScript application reads public aggregate evidence and precomputed audits. It uses relative assets, hash-based selections, classic-script data delivery and a light startup default for anonymous static hosting.

From the release root, install locked dependencies with `npm --prefix research_companion ci`, then `make build-site` and `python3 tools/serve_prefix.py`. Read [REPRODUCIBILITY](../docs/REPRODUCIBILITY.md) for tests, generated asset synchronization and Pages-prefix/sandbox routes. Canonical documentation is `../docs/`; scientific assets are `../reproducibility_artifact/`. `public/` and `../site/` are generated hosting copies.

When the anonymous sandbox blocks downloads, filtered JSON has a copyable preview. The scientific archive is also available through the anonymous repository. No direct personal GitHub or Pages link is introduced.
